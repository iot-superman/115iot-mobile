## 概述

**EX2** 是一個股票數據分析工具集，包含三個 Python 程序，用於從 FinMind API 獲取台積電(2330)股票數據，並進行數據可視化分析。

### 程序等級
- **初級 (EX2-1, EX2-2)**: 專注於單一功能的簡單程序
- **進階 (EX2-3)**: 完整的交互式工具，支持自定義參數

---

## 三個程序說明

### 📊 EX2-1.py - 收盤價走勢圖分析

**描述**: 繪製股票收盤價變化趨勢圖

**特點**:
- 自動從 FinMind API 獲取數據
- 股票代碼: 2330 (台積電) - 固定
- 時間範圍: 2026-01-01 ~ 2026-09-30 - 固定
- 包含 179 筆交易記錄

**輸出**:
- PNG 圖表: `EX2-1_close_price.png`
- 統計信息: 最高價、最低價、平均價、振幅

**運行**:

**適用場景**:

- 初階數據分析

### API 接口

**端點**: `https://api.finmindtrade.com/api/v4/data`

**參數示例**:
```python
params = {
    "dataset": "TaiwanStockPrice",      # 數據集
    "data_id": "2330",                  # 股票代碼
    "start_date": "2026-01-01",         # 開始日期
    "end_date": "2026-09-30"            # 結束日期
}
```

### 返回數據結構

```python
{
    "data": [
        {
            "date": "2026-01-02",
            "stock_id": "2330",
            "open": 1555.0,
            "max": 1585.0,
            "min": 1545.0,
            "close": 1585.0,
            "spread": 35.0,
            "Trading_Volume": 39836425,
            "Trading_money": 62469965712,
            "Trading_turnover": 77972

        ...
    ]

```

### 數據欄位說明

| 欄位 | 說明 | 單位 |
|-----|------|------|
| date | 交易日期 | YYYY-MM-DD |
| stock_id | 股票代碼 | - |
| open | 開盤價 | 元 |
| max | 最高價 | 元 |
| min | 最低價 | 元 |
| close | 收盤價 | 元 |
| spread | 漲跌 (close - 前日 close) | 元 |
| Trading_Volume | 成交股數 | 股 |
| Trading_money | 成交金額 | 元 |
| Trading_turnover | 成交筆數 | 筆 |

## 常見問題

### Q1: 程序無法連接到 API
**A**: 
1. 檢查網絡連接
2. 檢查防火牆設置
3. API 服務器可能暫時不可用，請稍後重試

### Q2: 出現 "ModuleNotFoundError: No module named 'requests'"
**A**: 需要安裝依賴包
```bash
pip install requests pandas matplotlib
```

### Q3: 股票代碼無效 (EX2-3)
**A**: 確保使用正確的台灣股票代碼，例如:
- 2330 - 台積電
- 3008 - 力磊
- 2303 - 聯電

### Q4: 日期範圍無數據
**A**: 
- 確保日期在股票交易期間內
- 檢查日期格式 (必須是 YYYY-MM-DD)
- 周末和假日沒有交易數據

### Q5: CSV 文件編碼問題
**A**: 使用 UTF-8 編碼打開
- Excel: 選擇 "從文本導入" 並設置編碼為 UTF-8
- 編輯器: 確保設置為 UTF-8 編碼

### Q6: 圖表未顯示或保存失敗
**A**:
1. 檢查磁盤空間
2. 確保 c:\dvds\AI_APP\EX2\ 目錄可寫
3. 關閉其他可能鎖定文件的應用

### Q7: 如何修改固定的股票代碼 (EX2-1/EX2-2)
**A**: 編輯程序文件，修改以下行:
```python
stock_id = "2330"  # 改為你想要的股票代碼
```

### Q8: 如何修改時間範圍 (EX2-1/EX2-2)
**A**: 編輯程序文件，修改以下行:
```python
start_date = "2026-01-01"  # 改為開始日期
end_date = "2026-09-30"    # 改為結束日期
```
