此任務包含三個股票數據分析程序，分別實現不同的功能級別，使用 FinMind API 獲取台積電(2330)股票數據，並進行可視化分析。

## ✅ 三個程序詳細說明

### 📊 **1. EX2-1.py - 收盤價走勢圖**

**功能描述:**
- 自動獲取指定股票（2330）的歷史數據
- 繪製收盤價走勢圖
- 顯示數據統計分析

**技術特點:**
- 使用固定的股票代碼: 2330（台積電）
- 固定時間範圍: 2026-01-01 到 2026-09-30
- 包含 179 筆交易數據
- 圖表含網格線、標籤和清晰的日期標記

**輸出文件:**
- `EX2-1_close_price.png` (54.13 KB)

**統計數據:**
```
最高價: 2510.0
最低價: 1585.0
平均價: 2162.21
振幅: 925.0 元
```

**運行方式:**
```bash
python EX2-1.py
```

### 🎯 **3. EX2-3.py - 互動式分析工具（進階版本）**

**功能描述:**
- 提供用戶交互界面，支持自定義查詢參數
- 允許用戶輸入股票代碼
- 允許用戶輸入自定義的開始和結束日期
- 自動繪製收盤價和成交量走勢圖
- 導出查詢結果到 CSV 文件
- 提供詳細的數據統計

**技術特點:**
- 完整的輸入驗證機制
- 錯誤處理（如無效股票代碼、網絡連接問題等）
- 生成三種輸出文件（2 個圖表 + 1 個 CSV）
- 友善的用戶界面和清晰的輸出信息
- 支持不同時間範圍的自定義查詢

**輸出文件（示例，使用 2026-09-01 到 2026-09-30）:**
- `EX2-3_2330_close_price.png` (45.11 KB)
- `EX2-3_2330_volume.png` (60.69 KB)
- `2330_2026-09-01_2026-09-30.csv` (1.6 KB)

**交互流程:**
```
1. 請輸入股票代碼 (例: 2330): [用戶輸入]
2. 請輸入起始日期 (YYYY-MM-DD): [用戶輸入]
3. 請輸入結束日期 (YYYY-MM-DD): [用戶輸入]
4. 程序自動獲取數據並生成分析結果
```

**範例運行:**

## 🔧 技術架構

### 使用的庫
- **requests**: HTTP 請求，獲取 API 數據
- **pandas**: 數據處理和分析
- **matplotlib**: 數據可視化和圖表生成

### API 源
- **服務**: FinMind API
- **URL**: https://api.finmindtrade.com/api/v4/data
- **數據集**: TaiwanStockPrice（台灣股票價格）
