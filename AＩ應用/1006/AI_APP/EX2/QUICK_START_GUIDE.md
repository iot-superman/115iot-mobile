## 常見問題

### Q: 運行程序時出現 "ModuleNotFoundError"
**A:** 需要安裝依賴包
```bash
pip install requests pandas matplotlib
```

### Q: API 連接失敗
**A:** 檢查網絡連接，或者數據源可能暫時不可用

### Q: 找不到指定的股票代碼
**A:** 檢查股票代碼是否正確（EX2-3.py），例如台積電是 2330

### Q: CSV 文件打開亂碼
**A:** 確保用正確的編碼打開（UTF-8），或用 Excel 打開



### 數據欄位
```

spread            - 漲跌
```
